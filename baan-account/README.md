# บัญชีบ้านเรา — แอพรายรับรายจ่ายครอบครัว + ร้านขายข้าว

เว็บแอพไฟล์ธรรมดา (HTML/CSS/JS) **ไม่ต้อง build** — Cloudflare Pages ดึงจาก GitHub ได้ทันที ข้อมูลเก็บที่ Supabase

## โครงไฟล์
```
index.html        หน้าเว็บ
style.css         สไตล์
js/config.js      ใส่ค่า Supabase ที่นี่ (ไฟล์เดียวที่ต้องแก้) — ไม่อยู่ในไฟล์ zip รอบอัปเดต เพื่อไม่ให้ทับค่าของคุณ
js/config.example.js   ตัวอย่างไฟล์ตั้งค่า (ถ้ายังไม่มี js/config.js ให้คัดลอกไปตั้งชื่อ config.js)
js/app.js         ตัวแอพ
js/parser.js      ตัวแยกรายการ/หมวดจากข้อความ (คำสำคัญ)
js/themes.js      ธีม 150 ชุด
js/db.js, charts.js
supabase/schema.sql   สร้างตารางในฐานข้อมูล
```

## ขั้นตอน (ทำครั้งเดียว ~15 นาที)

### 1) Supabase (ฐานข้อมูล)
1. สมัคร/เข้า https://supabase.com → **New project** (ตั้งชื่อ ตั้งรหัส เลือก region Singapore)
2. เมนู **SQL Editor → New query** → วางเนื้อหาไฟล์ `supabase/schema.sql` ทั้งไฟล์ → **Run**
3. เมนู **Project Settings → API** → คัดลอก **Project URL** และ **anon public key**
4. เปิดไฟล์ `js/config.js` แล้วแทนที่ `YOUR_SUPABASE_URL` และ `YOUR_SUPABASE_ANON_KEY`
   (ใช้คีย์ **anon** เท่านั้น ห้ามใช้ `service_role`)

### 2) GitHub
1. สร้าง repository ใหม่ (เช่น `baan-account`) 
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ลากวางในหน้าเว็บ GitHub ได้ หรือใช้ `git push`)

### 3) Cloudflare Pages
1. https://dash.cloudflare.com → **Workers & Pages → Create → Pages → Connect to Git**
2. เลือก repo `baan-account`
3. ตั้งค่า build: **Framework preset = None**, **Build command = (เว้นว่าง)**, **Build output directory = `/`**
4. กด **Save and Deploy** → ได้ลิงก์ `https://ชื่อ.pages.dev` ใช้ได้ทุกเครื่องในบ้าน
   (บนมือถือ เปิดลิงก์ด้วย Chrome/Safari โดยตรง (ไม่ใช่ผ่านเบราว์เซอร์ใน Messenger/LINE) แล้วเลือก "เพิ่มลงหน้าจอหลัก")

แก้โค้ดภายหลัง → push ขึ้น GitHub → Cloudflare อัปเดตให้เอง

## วิธีใช้
- **จดรายการ**: พิมพ์/วางหลายบรรทัดได้ เช่น
  `เกดใช้เงินวันนี้ไป 50 บาท` · `ซื้อถ่านปิ้งย่าง 40 บาท ซื้อขนม 15 บาท` · `ขายของ 1135`
  ระบุชื่อ `เกด: ข้าว 50` หรือ `@เกด ข้าว 50` · รายรับใส่ `+` นำหน้า · วันที่ `เมื่อวาน` / `27/10`
- แก้คำสำคัญของหมวดได้ที่ **ตั้งค่า → หมวดหมู่และคำสำคัญ**
- **ร้านข้าว**: กรอกยอดขาย ต้นทุน กำไร (กรอกเอง) → แบ่งกำไรให้ 3 ส่วนตาม % ที่ตั้งไว้
  ตัวอย่าง กำไร 400, เก็บ 50% / ทุนสำรอง 15% / ที่เหลือ 35% ให้เกด = 200 / 60 / 140
  ตั้งชื่อหัวข้อและ % ได้ที่ "ตั้งค่าการแบ่งกำไรและทุน" ท้ายหน้า (ยอดที่จดไปแล้วไม่เปลี่ยนตาม)

## อัปเดตครั้งนี้ (ถ้าเคยใช้เวอร์ชันก่อนแล้ว)
1. **รัน `supabase/schema.sql` ใหม่อีกครั้ง** ใน SQL Editor (รันซ้ำได้ ข้อมูลเดิมไม่หาย) เพื่อสร้างตาราง `pot_moves` สำหรับบันทึกเงินเข้า/ออกของ 3 กอง
2. อัปโหลดไฟล์ใหม่ทับขึ้น GitHub (ต้องมีโฟลเดอร์ `icons/` และไฟล์ `manifest.webmanifest`, `sw.js` ด้วย) **ห้ามทับ `js/config.js` ของคุณ** (รอบนี้ไม่มีไฟล์นี้ใน zip แล้ว) ถ้าเผลอทับ ให้ใส่ URL กับ anon key กลับเข้าไป แล้วเปิดแอพ จะมีปุ่ม “ย้ายขึ้น Supabase” สำหรับข้อมูลที่จดไว้ในเครื่อง
3. **ติดตั้งเป็นแอพบนมือถือ** (ให้เปิดเป็นหน้าต่างของตัวเอง ไม่เปิดแท็บใหม่ซ้ำ): ลบทางลัดเก่าบนหน้าจอโฮม แล้วเพิ่มใหม่
   - iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   - Android: Chrome → เมนู ⋮ → ติดตั้งแอพ
4. หมวดใหม่ “ซื้อของเข้าร้าน” ใช้คิดทุนหมุนเวียน — รายการซื้อของที่จดไว้เดิม ให้กดปุ่ม “จัดรายการซื้อของย้อนหลัง” ในหน้าร้านข้าวเพื่อย้ายเข้าหมวดนี้

## หมายเหตุด้านความปลอดภัย
ตามที่ตกลงกัน แอพไม่มีรหัสผ่าน ดังนั้น **ใครมีลิงก์เว็บก็เปิด/แก้ข้อมูลได้** อย่าแชร์ลิงก์นอกครอบครัว
ถ้าภายหลังอยากกันคนนอก ใช้ Cloudflare Access (ฟรี) ครอบหน้าเว็บด้วยอีเมลคนในบ้านได้ โดยไม่ต้องแก้โค้ด

ถ้ายังไม่ใส่ค่า Supabase แอพจะเป็น "โหมดทดลอง" เก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเท่านั้น

## อัปเดตรอบ 4 (ต้องรัน SQL หนึ่งครั้ง)
1. Supabase > SQL Editor > วางไฟล์ `supabase/update-pot.sql` แล้วกด Run (ข้อมูลเดิมไม่หาย)
2. อัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้น GitHub ทับของเดิม **ยกเว้น `js/config.js`** (ของคุณมี URL/key อยู่แล้ว ไม่ต้องทับ)

อัปเดตรอบ 5: รัน `supabase/update-pot.sql` ใหม่อีกครั้ง (ช่อง “จ่ายจาก” รองรับการ์ดกระเป๋าเงินที่สร้างเอง)

อัปเดตรอบ 6: ไม่ต้องรัน SQL เพิ่ม อัปโหลดไฟล์ทับ (ยกเว้น js/config.js)
